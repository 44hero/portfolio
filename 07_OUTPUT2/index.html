    金魚 rig¶

    ■実行サンプル¶

    有料モデルデータを購入し、rig を仕込みました。

    ■制作物PR¶

    ●概要¶

    金魚のrig です。

    ●詳細¶

    有料モデルデータを購入し、金魚のrig を仕込みました。
    アニメータさんに渡す際、mayaの作業における取り回しが軽快な 軽い rigデータ 作成 を目標に据えた データ です。

    ●開発の経緯・ストーリー¶

    アニメータさんにお渡しする際、mayaの実作業において、取り回しが軽快な 軽い rigデータ を提供することは、非常に重要です。
    実作業で起こりうる問題発生を想定し、予め解消しながら、rig を作成いたしました。

    こだわったところは、

    1. rig, skinning, を完全に役割で分離した、階層構造を意識
    2. ローカル空間でのskinning
    3. ワールド空間での、maya 標準のコンストレインノードの使用を避ける
    4. その際、マトリックスを利用した、コンストレインの代用テクニックの利用
    5. skinningを極力単純化し、skin cluster のレイヤー化による、複雑なデフォーム表現の実現
    6. その際、skinningのダブルトランスフォームの発生に対応した、インバースマトリックステクニックの利用
    7. 二股の尾びれ其々の splineIK に対する、world空間とlocal空間のスイッチを実現

    です。

    ●使用した技術¶

    データ作成には 様々な 自作の python コーディング ツール を使用しております。

    もちろん、外部有志の方々のツールも積極的に活用させていただいています。

    ●使用した技術の選定理由¶

    世の中には、
    mGear, Advanced Skeleton, eST3 等、商用無料・商用有料の plug-in も内包したツールが、多数存在します。
    オープンソースなものオープンソースでないもの、多数ございます。

    しかしながら、
    たとえオープンソースだとは言え、基本的な仕組みを理解した上での、それらのツールの使用でないと、
    いつまでもツールの仕様の呪縛からは解放されることは無く、仕様に支配される形となります。

    なぜ、そういう仕組みなのかという、疑問の方が重要だと考えます。

    リガーにとっては決して避けて通れないテクニカルな問題にぶち当たったときにも、混乱してしまいます。

    この度の取り組みとして、一番気を使ったところは、

    • 例え新しい環境であっても、柔軟に対応できる基本のスキルセットを、この身に叩き込み、身に着けておくこと

    です。

    そこでこの度、
    フルスクラッチで、
    実作業で起こりうる問題発生を想定し、予め解消しながら、rig を作成いたしました。
    非常に手間と時間のかかる作業です。

    ●将来について¶

    時間は要しますが、私は、疑問を解消するために時間を惜しみません。
    そして、実情に甘えることなく、更に高みを目指し、実体験を基盤とし、

    -補足-有名なツールについて

    ■mGearとAdvanced Skeleton：オープンソースとプラグイン

    • mGear:
      • オープンソース:
        mGearはMaya用のオープンソースのリギングフレームワークで、リギングプロセスを簡素化するツールとモジュールを提供しています。
      • プラグイン:
        mGearが提供するプラグインやツールもオープンソースであり、ユーザーはこれらを自由に修正・拡張することができます。
        mGearフレームワーク ページへ移動
      • 無料ツール
        寄付などを通じてプロジェクトをサポートすることが可能です。
    • Advanced Skeleton:
      • 非オープンソース:
        Advanced Skeletonはプロプライエタリなツールで、全機能を利用するためにはライセンスが必要です。
      • プラグイン:
        Advanced Skeletonのプラグインや機能はライセンスに含まれており、オープンソースではありません。
        animation-studios ページへ移動
      • 有料ツール

    ■他のフルスクラッチでリグを作成できるツール

    • 無料ツール:

      • eST3:
        • 概要:
          eST3は、日本のPolygon Pictures Inc.が開発したリギングとアニメーションのフレームワークで、主にAutodesk Mayaと連携して使用されます。これにより、リギングやアニメーションの開発を支援するさまざまなツールが提供されます。
        • 利用環境:
          Windows 10およびLinuxで動作し、Maya 2020, 2022, 2023, 2024と互換性があります。Pythonのバージョンは2.7, 3.7, 3.9, 3.10がサポートされています。
        • 配布形態:
          eST3は無料で配布されていますが、開発中のためバグや未完成の機能が含まれる可能性があります。公式なサポートは提供されておらず、インストールやバグに関する問い合わせはBorn Digitalに行うことができますが、バグ修正の保証はありません。
        • アクセス:
          ファイルのダウンロードにはパスワードが必要で、これはBorn Digitalから受け取ることができます。
        • 非オープンソース
        • まとめ
          eST3は、日本国内で開発されている無料のリギングツールであり、オープンソースではありませんが、利用には制限がないため、多くのユーザーにとって有用なツールとなるでしょう。
          eST3の公式サイト ページへ移動
      • Raid Rig:
        高機能なオートリグツールで、無料版も提供されています。最新バージョンはMaya 2024に対応しています。
        Rapid Rig無料版 ページへ移動
      • Ninja Rigs:
        さまざまな無料のMayaリグを提供しており、NinjaやLink、Zeldaなど人気キャラクターのリグがあります。
        Rusty Animator ページへ移動
      • Arise Rigging System:
        高度にカスタマイズ可能なノードベースのリギングシステム。ノードを自由に組み合わせて独自のリグを作成できます。
        Arise Rigging ページへ移動

    • 有料ツール:

      • Rapid Rig:

        • 特徴: 人間、動物、クリーチャー用の自動リグツール、高度なカスタマイズ可能なリグ設定。
        • 価格: 有料, 非オープンソース
        • 詳細: Rapid Rig有料版

      • Rigger:

        • 特徴: 3Dキャラクターやプロップのカスタムリグ、IK/FK/IKスプラインのシームレスな切り替え、ストレッチ機能、ミラーリングおよびフリップポーズ。
        • 価格: 有料, 非オープンソース
        • 詳細: Rigger

      • Mansur-Rig:

        • 特徴: カスタムリギングソルバーライブラリ、モジュール式のアプローチ、ガイドオブジェクトからのリグ構築および分解。
        • 価格: 有料, 非オープンソース
        • 詳細: Mansur-Rig

    これらのツールは、フルスクラッチでリグを作成するための強力な機能を提供しており、ユーザーのリギングプロセスを大幅に簡素化します。興味のあるツールを試して、自分のニーズに合ったものを見つけてください。
